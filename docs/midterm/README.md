## 构建

核验环境为 Typst 0.15.1，字体为 Noto Serif SC、Microsoft YaHei、Consolas。绘图仅使用 Python 标准库，首次编译需要取得模板依赖包。

在本目录打开PowerShell，逐行执行：

~~~powershell
python draw_design.py
python draw_supplement.py
typst compile report.typ 中期设计文档-工作稿.pdf
~~~

只改正文时执行第三行，输出工作稿后人工核对再发布，不直接覆盖任何已批准基线。本轮保留已有源稿改动，未重新编译验证源稿与交付 PDF 的对应关系。迁移到其他电脑时需安装上述字体，替换字体可能改变分页。文档中的图为设计原型，不是已实现页面的截图；测试表为验收方案。
